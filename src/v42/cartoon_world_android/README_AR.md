# عالم الكرتون 4.0 — تطبيق Android

تطبيق شخصي لحفظ ومشاهدة ملفات الكرتون والأنمي على جهازك. واجهة عربية حديثة، شريط تنقل سفلي، إحصائيات، واستكمال المشاهدة.

## الجديد في النسخة 4.0
- واجهة معاد تصميمها بالكامل (أكثر شبهاً بالتطبيقات الحقيقية)
- شريط تنقل سفلي: الرئيسية • مكتبتي • المفضلة • المزيد
- صفحة إحصائيات (عدد العناوين، الحلقات، المفضلة، دقائق المشاهدة)
- إبقاء الشاشة مضاءة أثناء التشغيل
- مشاركة التطبيق من الإعدادات
- تحسينات في الأداء واللمس والتصميم المتجاوب

## الميزات
- فهرس عناوين كرتون وأنمي شائعة (أسماء فقط)
- إضافة / تعديل / حذف عناوينك الخاصة
- استيراد فيديوهات من جهازك وحفظها داخل التطبيق
- استكمال المشاهدة من آخر نقطة
- مفضلة، بحث، تصفية حسب التصنيف
- تصدير واستعادة نسخة JSON للعناوين والمفضلة
- يعمل دون إنترنت بعد التثبيت

## بناء APK (موصى به عبر GitHub Actions)
1. أنشئ مستودع GitHub جديد
2. ارفع **محتويات** هذا المجلد
3. Actions → **Build Cartoon World APK** → Run workflow
4. نزّل الـ Artifact واستخرج `app-debug.apk`

أو افتح المجلد في Android Studio → Build APK(s)  
أو من الطرفية: `./gradlew assembleDebug`

## ملاحظات
- لا توجد حلقات مضمّنة. استورد فقط ملفات تملك حق استخدامها.
- الفيديوهات تُخزَّن داخل مساحة التطبيق.
- النسخة الاحتياطية لا تشمل ملفات الفيديو.
