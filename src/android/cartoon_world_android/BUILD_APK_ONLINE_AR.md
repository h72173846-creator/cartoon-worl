# بناء APK لعالم الكرتون 3.1 (مجانًا ومن الإنترنت فقط)

> لم يُبنَ APK في بيئة إعداد المشروع لأنها لا تحتوي Android SDK ولا Gradle ولا اتصالًا بالإنترنت. البناء يتم على خوادم GitHub المجانية.

## الخطوات (من متصفح الهاتف أو الحاسوب)
1. أنشئ حسابًا مجانيًا على github.com ثم مستودعًا جديدًا (New repository).
2. ارفع **محتويات** المجلد (الذي فيه `settings.gradle` و`app/` و`.github/`) عبر Add file ← Upload files. تأكد أن مجلد `.github` رُفع.
3. افتح تبويب **Actions** ← **Build Cartoon World APK** ← **Run workflow**.
4. بعد نجاح المهمة (علامة ✅، تستغرق نحو 5 دقائق) افتح تبويب **Releases** في الصفحة الرئيسية للمستودع، ونزّل `CartoonWorld.apk` مباشرة إلى هاتفك.
5. على الهاتف: اسمح بالتثبيت من مصدر غير معروف للمتصفح، ثم افتح الملف وثبّته.

النسخة الناتجة debug موقّعة بمفتاح تجريبي: مناسبة للتثبيت الشخصي وليست للنشر على المتجر.
