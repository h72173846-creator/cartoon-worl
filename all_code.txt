# بناء APK لعالم الكرتون 3.1 (مجانًا ومن الإنترنت فقط)

> لم يُبنَ APK في بيئة إعداد المشروع لأنها لا تحتوي Android SDK ولا Gradle ولا اتصالًا بالإنترنت. البناء يتم على خوادم GitHub المجانية.

## الخطوات (من متصفح الهاتف أو الحاسوب)
1. أنشئ حسابًا مجانيًا على github.com ثم مستودعًا جديدًا (New repository).
2. ارفع **محتويات** المجلد (الذي فيه `settings.gradle` و`app/` و`.github/`) عبر Add file ← Upload files. تأكد أن مجلد `.github` رُفع.
3. افتح تبويب **Actions** ← **Build Cartoon World APK** ← **Run workflow**.
4. بعد نجاح المهمة (علامة ✅، تستغرق نحو 5 دقائق) افتح تبويب **Releases** في الصفحة الرئيسية للمستودع، ونزّل `CartoonWorld.apk` مباشرة إلى هاتفك.
5. على الهاتف: اسمح بالتثبيت من مصدر غير معروف للمتصفح، ثم افتح الملف وثبّته.

النسخة الناتجة debug موقّعة بمفتاح تجريبي: مناسبة للتثبيت الشخصي وليست للنشر على المتجر.

# عالم الكرتون 3.1 — مشروع Android

نسخة مستقلة لمكتبتك الشخصية للكرتون. الواجهة عربية، مصممة للموبايل، وتعمل من ملفات التطبيق دون الحاجة إلى اتصال بالإنترنت بعد تثبيت APK.

## الميزات الموجودة
- فهرس أولي لعناوين كرتون وأنمي شائعة؛ هذه أسماء وفئات فقط وليست حلقات مرفقة.
- إضافة عناوينك وتعديلها وحذفها وإضافتها إلى المفضلة.
- استيراد ملفات فيديو من مدير ملفات Android وحفظها داخل مساحة التطبيق، ثم تشغيلها دون اتصال.
- حفظ مكان المشاهدة تلقائيًا وزر لاستكمال المشاهدة.
- تصفية المكتبة حسب المسلسل والبحث باسم الحلقة، وفرزها بالأحدث/الأقدم/الاسم/رقم الحلقة عندما يظهر الرقم في اسم الملف.
- إعادة تسمية الحلقة من داخل المكتبة.
- تصدير واستعادة نسخة JSON للعناوين المخصصة والمفضلة عبر نافذة حفظ الملفات في Android.
- مؤشر لمساحة التخزين وطلب إبقاء التخزين المحلي دائمًا عندما يدعم النظام ذلك.
- زر الرجوع في Android يغلق المشغل/نافذة الإضافة أو يرجع إلى الرئيسية قبل الخروج.

## بناء APK على Android Studio
1. فك ضغط الحزمة وافتح مجلد `cartoon_world_android` في Android Studio.
2. استخدم JDK 17، واسمح بمزامنة Gradle وتنزيل Android SDK Platform 35 عند الطلب.
3. من القائمة **Build → Build APK(s)**.
4. بعد نجاح البناء، ابحث عن الملف في `app/build/outputs/apk/debug/app-debug.apk`.

أو من طرفية داخل مجلد المشروع إذا كان Gradle وAndroid SDK مضبوطين: `gradle assembleDebug`.

## حدود النسخة
- هذه الحزمة **مشروع مصدر** وليست APK جاهزًا.
- لا توجد حلقات كرتون مضمّنة، ولا اتصال تلقائي بـStarDima. استورد فقط ملفات تملك حق استخدامها.
- ميزة حفظ الفيديو تخزن الملفات داخل مساحة التطبيق؛ حذف التطبيق أو مسح بياناته قد يحذف هذه الملفات. احتفظ بالملفات الأصلية على جهازك.
- النسخة الاحتياطية JSON تشمل العناوين المخصصة والمفضلة فقط؛ لا تشمل الفيديوهات ولا سجل المشاهدة.
- الترتيب برقم الحلقة يعتمد على وجود رقم واضح في اسم الملف؛ إذا لم يظهر رقم، قد يستخدم ترتيب الإضافة.
- لم يُنفذ بناء APK أو اختبار على جهاز Android في بيئة إعداد الحزمة لعدم توفر Android SDK/Gradle هنا. اختبر الاستيراد مع فيديو صغير قبل إضافة ملفات كبيرة.

## تعديلات 3.1 (هذه النسخة)
- تحميل الواجهة عبر `WebViewAssetLoader` (https://appassets.androidplatform.net) بدل `file://` لتخزين أكثر استقرارًا، وإغلاق وصول الملفات المباشر.
- تشغيل الفيديو بملء الشاشة، وإيقاف/استئناف WebView مع دورة حياة التطبيق.
- أيقونات تطبيق (adaptive + PNG) ولون شريط الحالة.
- إخفاء خيارات «تثبيت كتطبيق ويب» داخل التطبيق، وتحسينات لمس وهوامش آمنة للموبايل.
- سير عمل GitHub Actions يبني APK وينشره في Releases برابط تنزيل مباشر.
- **لم يُختبر البناء ولا التشغيل على جهاز في بيئة التطوير؛ أبلغ عن أي خطأ يظهر في سجل Actions.**

            .addPathHandler("/assets/", new WebViewAssetLoader.AssetsPathHandler(this))

        settings.setJavaScriptEnabled(true);

# بناء APK لعالم الكرتون 3.1

## طريقة الحصول على APK باستخدام GitHub Actions
1. أنشئ مستودعًا جديدًا على GitHub وارفع **محتويات** هذا المجلد إليه (المجلد الذي يحتوي `settings.gradle` و`app/`).
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build Cartoon World APK** ثم **Run workflow**.
4. بعد نجاح المهمة، افتح تشغيل المهمة وانزل إلى **Artifacts**.
5. نزّل `cartoon-world-debug-apk.zip` واستخرج منه `app-debug.apk`، ثم انقله إلى هاتف Android وثبّته.

هذا APK تجريبي debug وليس إصدارًا منشورًا على متجر. يجب أن تنجح مهمة البناء أولًا؛ لم يتم اختبار التطبيق على جهاز فعلي.

const DB_NAME = 'CartoonWorldDB', DB_VERSION = 2, VIDEO_STORE = 'videos', PROGRESS_STORE = 'progress';
let dbPromise;

function openDB(){
  if(!('indexedDB' in window)) return Promise.reject(new Error('التخزين المحلي غير مدعوم'));
  if(!dbPromise){
    dbPromise = new Promise((resolve,reject)=>{
      const req = indexedDB.open(DB_NAME, DB_VERSION);
      req.onupgradeneeded = ()=>{
        const db = req.result;
        if(!db.objectStoreNames.contains(VIDEO_STORE)){
          const s = db.createObjectStore(VIDEO_STORE,{keyPath:'id'});
          s.createIndex('addedAt','addedAt');
          s.createIndex('titleId','titleId');
        }
        if(!db.objectStoreNames.contains(PROGRESS_STORE)) db.createObjectStore(PROGRESS_STORE,{keyPath:'id'});
      };
      req.onsuccess = ()=>resolve(req.result);
      req.onerror = ()=>reject(req.error || new Error('تعذر فتح قاعدة البيانات'));
    });
  }
  return dbPromise;
}
function dbAction(store, mode, fn){
  return openDB().then(db=>new Promise((resolve,reject)=>{
    const tx = db.transaction(store, mode);
    const os = tx.objectStore(store);
    const req = fn(os);
    if(req && req.onsuccess !== undefined){
      req.onsuccess = ()=>resolve(req.result);
      req.onerror = ()=>reject(req.error);
    } else {
      tx.oncomplete = ()=>resolve();
      tx.onerror = ()=>reject(tx.error);
    }
  }));
}

function cardHtml(t, opts={}){
  const isFav = favorites.has(t.id);
  const vids = videos.filter(v=>v.titleId===t.id);
  const prog = vids.length ? Math.max(...vids.map(v=>{
    const p = progressMap.get(v.id);
    return p && p.duration ? (p.current/p.duration) : 0;
  })) : 0;
  const langBadge = t.lang ? `<span class="lang-badge ${t.lang==='مدبلج'?'dub':'sub'}">${esc(t.lang)}</span>` : '';
  return `<div class="card" onclick="openTitleEpisodes('${esc(t.id)}')">
    <button class="fav-btn ${isFav?'on':''}" onclick="event.stopPropagation();toggleFavorite('${esc(t.id)}')">${isFav?'★':'☆'}</button>
    <div class="card-banner" style="background:linear-gradient(135deg,${t.a||'#54377d'},${t.b||'#c95e91'})">${t.emoji||'🎬'}${langBadge}</div>
    <div class="card-body">
      <h4>${esc(t.short||t.name)}</h4>
      <p>${esc(t.category)}${vids.length?` • ${vids.length} حلقة`:''}</p>
      ${prog>0.02?`<div class="prog"><i style="width:${Math.min(100,prog*100)}%"></i></div>`:''}
      ${opts.showActions?`<div class="card-actions">
        <button class="btn small alt" onclick="event.stopPropagation();editTitle('${esc(t.id)}')">تعديل</button>
      </div>`:''}
    </div>
  </div>`;
}

  if(q) list = list.filter(t=>(t.name+t.short+t.desc+(t.lang||'')+t.category).toLowerCase().includes(q));
  $('catalog').innerHTML = list.map(t=>cardHtml(t)).join('') || '<div class="empty"><div class="big">🔍</div>لا توجد نتائج</div>';
  $('catalogCount').textContent = list.length;
}

function renderContinue(){
  const items = videos.map(v=>{
    const p = progressMap.get(v.id);
    if(!p || !p.duration || p.current < 5 || p.current/p.duration > 0.95) return null;
    return {v, p, ratio: p.current/p.duration};
  }).filter(Boolean).sort((a,b)=> (b.p.updated||0)-(a.p.updated||0)).slice(0,8);

  const sec = $('continueSection');
  if(!items.length){ sec.hidden = true; return; }
  sec.hidden = false;
  $('continueCount').textContent = items.length;
  $('continueGrid').innerHTML = items.map(({v,p})=>{
    const t = titleById(v.titleId) || {emoji:'🎬', short:v.titleId, a:'#54377d', b:'#c95e91'};
    return `<div class="card" onclick="playVideo('${esc(v.id)}')">
      <div class="card-banner" style="background:linear-gradient(135deg,${t.a},${t.b})">${t.emoji}</div>
      <div class="card-body">
        <h4>${esc(v.name)}</h4>
        <p>${esc(t.short||'')} • ${fmtTime(p.current)}</p>
        <div class="prog"><i style="width:${Math.min(100,(p.current/p.duration)*100)}%"></i></div>
      </div>
    </div>`;
  }).join('');
}

function formatSize(n){
  if(n<1024) return n+' بايت';
  if(n<1048576) return (n/1024).toFixed(1)+' ك.ب';
  return (n/1048576).toFixed(1)+' م.ب';
}
function fmtTime(s){
  s = Math.max(0, Math.floor(s||0));
  const h = Math.floor(s/3600), m = Math.floor((s%3600)/60), sec = s%60;
  return h ? `${h}:${String(m).padStart(2,'0')}:${String(sec).padStart(2,'0')}` : `${m}:${String(sec).padStart(2,'0')}`;
}

    private ValueCallback<Uri[]> fileCallback;
    private byte[] pendingBackup;
    private String pendingBackupName = "cartoon-world-backup.json";

    @Override

                    fileCallback = null;
                    callback.onReceiveValue(null);

                }

    private final class NativeBridge {

        public void saveBackup(String encoded, String fileName) {
            try {
                pendingBackup = Base64.decode(encoded, Base64.DEFAULT);
                pendingBackupName = (fileName == null || fileName.trim().isEmpty())
                        ? "cartoon-world-backup.json"
                        : fileName.replaceAll("[^a-zA-Z0-9._-]", "_");
                runOnUiThread(() -> {
                    Intent intent = new Intent(Intent.ACTION_CREATE_DOCUMENT);
                    intent.addCategory(Intent.CATEGORY_OPENABLE);
                    intent.setType("application/json");
                    intent.putExtra(Intent.EXTRA_TITLE, pendingBackupName);
                    try {
                        startActivityForResult(intent, SAVE_BACKUP);
                    } catch (Exception e) {
                        pendingBackup = null;
                        Toast.makeText(MainActivity.this, "تعذر فتح نافذة حفظ الملف", Toast.LENGTH_LONG).show();
                    }
                });
            } catch (Exception e) {
                runOnUiThread(() -> Toast.makeText(MainActivity.this, "تعذر تجهيز النسخة الاحتياطية", Toast.LENGTH_LONG).show());
            }
        }

        public void setKeepScreenOn(boolean keepOn) {
            runOnUiThread(() -> {
                if (keepOn) {
                    getWindow().addFlags(WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON);

                    getWindow().clearFlags(WindowManager.LayoutParams.FLAG_KEEP_SCREEN_ON);

        public void shareText(String title, String text) {
            runOnUiThread(() -> {

        if (requestCode == FILE_PICKER && fileCallback != null) {

            fileCallback.onReceiveValue(result);
            fileCallback = null;
            return;
        }

                    if ("false".equals(value) || value == null) {

                    }
                });
    }

    @Override
    protected void onDestroy() {
        if (fileCallback != null) {
            fileCallback.onReceiveValue(null);
            fileCallback = null;
        }
        if (webView != null) {
            webView.removeJavascriptInterface("CartoonWorldNative");
            webView.destroy();
            webView = null;
        }
        super.onDestroy();
